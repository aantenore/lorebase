# lorebase-guide

Part of [Lorebase](https://github.com/aantenore/lorebase), an open-source ontology platform: a versioned, governed knowledge graph on Postgres with git-like branching and three-way merge.

Guide, the optional exploration assistant of Lorebase over Keeper, and its query embedding endpoint.

```sh
uv tool install lorebase-guide    # or: pip install lorebase-guide
lorebase-guide --help
```

Documentation: [Guide](https://aantenore.github.io/lorebase/guide/) and the [documentation site](https://aantenore.github.io/lorebase/). License: Apache-2.0.
