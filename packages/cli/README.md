# lorebase-cli

Part of [Lorebase](https://github.com/aantenore/lorebase), an open-source ontology platform: a versioned, governed knowledge graph on Postgres with git-like branching and three-way merge.

The `lorebase` command line for a Keeper: schema, records, imports, branches, merges, search and queries.

```sh
uv tool install lorebase-cli    # or: pip install lorebase-cli
lorebase --help
```

Documentation: [Manual setup](https://aantenore.github.io/lorebase/manual-setup/) and the [documentation site](https://aantenore.github.io/lorebase/). License: Apache-2.0.
