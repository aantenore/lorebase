# lorebase-client

Part of [Lorebase](https://github.com/aantenore/lorebase), an open-source ontology platform: a versioned, governed knowledge graph on Postgres with git-like branching and three-way merge.

Typed sync and async Python client for the Keeper REST API.

```sh
pip install lorebase-client
```

A library: it has no command of its own.

Documentation: [Agents](https://aantenore.github.io/lorebase/agents/) and the [documentation site](https://aantenore.github.io/lorebase/). License: Apache-2.0.
