# lorebase-platform

Part of [Lorebase](https://github.com/aantenore/lorebase), an open-source ontology platform: a versioned, governed knowledge graph on Postgres with git-like branching and three-way merge.

The shared runtime of the Lorebase services: layered settings, secret references, structured logging and OpenTelemetry setup.

```sh
pip install lorebase-platform
```

It is a library of the other Lorebase packages and has no command of its own.

Documentation: [Operations](https://aantenore.github.io/lorebase/operations/) and the [documentation site](https://aantenore.github.io/lorebase/). License: Apache-2.0.
