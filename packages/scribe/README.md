# lorebase-scribe

Part of [Lorebase](https://github.com/aantenore/lorebase), an open-source ontology platform: a versioned, governed knowledge graph on Postgres with git-like branching and three-way merge.

Scribe, the job worker and scheduler of Lorebase: Source synchronization, extraction, webhooks, index jobs and maintenance passes.

```sh
uv tool install lorebase-scribe    # or: pip install lorebase-scribe
lorebase-scribe --help
```

Documentation: [Scribe](https://aantenore.github.io/lorebase/scribe/) and the [documentation site](https://aantenore.github.io/lorebase/). License: Apache-2.0.
