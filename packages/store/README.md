# lorebase-store

Part of [Lorebase](https://github.com/aantenore/lorebase), an open-source ontology platform: a versioned, governed knowledge graph on Postgres with git-like branching and three-way merge.

The persistence layer of Lorebase on Postgres with pgvector: repositories, Alembic migrations (shipped in the wheel) and the materializer of branch heads.

```sh
pip install lorebase-store
```

It is a library of the other Lorebase packages and has no command of its own.

Documentation: [Store schema notes](https://aantenore.github.io/lorebase/store-schema-notes/) and the [documentation site](https://aantenore.github.io/lorebase/). License: Apache-2.0.
