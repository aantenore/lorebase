# lorebase-inference

Part of [Lorebase](https://github.com/aantenore/lorebase), an open-source ontology platform: a versioned, governed knowledge graph on Postgres with git-like branching and three-way merge.

Model-agnostic providers for chat, embeddings and span extraction, over any compatible HTTP endpoint or in-process models (extras `fastembed` and `local-extractors`).

```sh
uv tool install lorebase-inference    # or: pip install lorebase-inference
lorebase-inference --help
```

Documentation: [Inference](https://aantenore.github.io/lorebase/inference/) and the [documentation site](https://aantenore.github.io/lorebase/). License: Apache-2.0.
