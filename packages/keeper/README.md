# lorebase-keeper

Part of [Lorebase](https://github.com/aantenore/lorebase), an open-source ontology platform: a versioned, governed knowledge graph on Postgres with git-like branching and three-way merge.

Keeper, the REST API service of Lorebase: schema, records, branches, merges, Proposals, search and the read API agents use.

```sh
uv tool install lorebase-keeper    # or: pip install lorebase-keeper
lorebase-keeper --help
```

Documentation: [Deployment](https://aantenore.github.io/lorebase/deployment/) and the [documentation site](https://aantenore.github.io/lorebase/). License: Apache-2.0.
